## Intended workflow

Home → Samples → Prepared sample preview/download, or Home → Sign In / Sign Up → Verify Email → approved Projects or Access Status. Password recovery: Forgot Password → Reset Password → Password Updated → Sign In. Creator: Projects → Idea → Storyboard approval → Generating → Video Review → Publish/download or simulated schedule/result. Revisions return to the relevant stage; failure states keep recoverable work available.
